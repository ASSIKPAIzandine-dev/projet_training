ASCIIDOC

Qu’est-ce que AsciiDoc?

Asciidoc est un format de fichier texte qui permet d’écrire des documents (livres, articles, pages web, blogs, …​).

Il définit des constructions syntaxiques qui aideront à comprendre la sémentique des différentes parties de votre texte afin de produire une sortie bien formatée. Cette sortie formatée est un document de format publiable (HTML, DocBook, PDF, ePub, …​).

Certains caractères dans votre document textuel ont une signification spéciale qui va changer le rendu du document. C’est exactement le même concept que les balises en HTML. Mais une différence clé avec AsciiDoc est la propriété du document source à rester même lisible par l’homme.

L’utilisation d’un format textuel a plusieurs avantages :

  • Le document est facilement lisible et modifiable,

  • la taille des documents est très légère.

Comment écrire dans AsciiDoc?

Comme je l’ai dit plus haut, AsciiDoc est un humain lisible format de fichier texte. Ainsi, vous pouvez écrire vos documents en utilisant l’éditeur de texte de votre choix.

L’extension des fichiers AsciiDoc est .adoc.

Le formatage du texte

Pour un texte organisé en paragraphes, il n’y a pas de syntaxe particulière pour les délimiter. Les lignes de texte adjacentes ou consécutives forment un paragraphe. Pour commencer un nouveau paragraphe après un autre, il suffit d’utiliser une ligne vide.

Il est aussi possible de forcer un retour chariot à la fin d’une phrase en utilisant un espace suivi du caractère plus (+).

Exemple :

Première ligne du paragraphe.
Elle se poursuit avec une seconde
ligne qui fait elle même partie du
paragraphe


Texte avec saut de ligne forcé +
Ligne suivante

Rendu

Ligne suivante

  • les caractères italiques entre les underscores,

Exemple :

On utilise les caractères slash (//) pour les commentaires niveau ligne.

Les titres des sections

Un document comporte normalement un seul grand titre et un ou plusieurs niveaux de sous-titres. AsciiDoc ne gère que trois niveaux de sous-titres (sections).

= Titre du document AsciiDoc =
== sous-titre niveau 1 ==
=== sous-titre niveau 2 ===
==== sous-titre niveau 3 ====
Les blocs

Les blocs permettent de structurer du texte. Différents types de blocs sont utilisables. Ils se définissent avec une suite d’au moins quatre caractères selon leur type et se terminent avec la même suite de caractères. Il est recommandé de n’utiliser que quatre caractères.

Séquences de caractères

Rôles

----

Bloc permettant de délimiter un contenu généralement pour les codes sources

////

Bloc de commentaires

….

Bloc littéral ; restitue le texte tel qu’il est fourni

* * * *

Bloc de type sidebar ; le contenu est restitué en dehors du flux
Les listes

AsciiDoc supporte plusieurs types de listes.

Les listes ordonnées

Elles sont définies avec le caractère point (.) suivi d’un espace et supportent aussi le multi-niveau.

.Les éléments ordonnés sont :
. élément 1
. élément 2
.. élément 2.1
... élément 2.1.1
.. élément 2.2
. élément 3
Les éléments ordonnés sont :

  1. élément 1

  2. élément 2

    1. élément 2.1

      1. élément 2.1.1

    2. élément 2.2

  3. élément 3

Les listes non-ordonnées

Elles sont définies avec le caractère de multiplication (*).

* Python
* Java
* Perl
* C++

Les tableaux

Un tableau est défini comme un bloc particulier avec la séquence |===. Chaque cellule du tableau est définie avec un caractère |
Par défaut le nombre de colonnes est déterminé par la première ligne qui vient juste après le délimiteur de tableau.

Les codes sources

AsciiDoc permet d’intégrer du code source dans le document. AsciiDoctor supporte plusieurs outils de coloration syntaxique qui pourront améliorer la lisibilité du code dans les documents générés.

Exemples :
Select * From commande;
package Documents.s4.prog_objet;

public class HelloPrenom {

        public static void main(String[] args) {
                System.out.println("Bonjour "+ args[0]+args[1]+" "+args[2] +" !");
                System.out.println(args.length);
        }
}
Les images

Il est possible d’ajouter des images en utilisant la syntaxe image:: suivi du chemin de l’image puis d’une paire de crochets qui peut contenir un texte alternatif.

image::logoIfnti.png[Logo IFNTI]
Les liens

AsciiDoc reconnaît de façon automatique les liens vers http, https, mailto, ftp et callto.

Exemple de lien vers le site IFNTI

http://www.ifnti.org

Il est aussi possible de définir des liens locaux qui pointent sur un autre document html de votre machine. Pour ce faire, on utilise le mot clé link: suivi du chemin du fichier puis d’une paire de crochets qui peut contenir un texte alternatif.

Syntaxe :
link:chemin_fichier[nomLien]
Exemple :
link:premierEssai.html[Identité]

Identité

Comment rendre la sortie finale?

Pour convertir un document d’extension .adoc en HTML à partir d’une ligne de commande, vous ouvrez une console ensuite lancez la commande asciidoc, suivi du nom du document que vous voulez convetir.
La sortie formatée par défaut d’AsciiDoc est html5, donc ce n’est plus nécessaire de la spécifier avec la commande -b

$ asciidoc premierEssai.adoc
